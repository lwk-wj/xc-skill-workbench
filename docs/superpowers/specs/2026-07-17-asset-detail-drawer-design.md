# 资源详情抽屉设计

## 背景

当前资源详情固定占据主网格右侧 `280px`。扣除内边距后，Markdown 正文、四个详情标签和安装状态只能在约 `236px` 的区域内展示，阅读密度过高，也挤压了资源列表。

## 已确认方案

资源详情从固定第三栏改为 Element Plus 右侧抽屉。主界面只保留来源侧栏和资源浏览器两列；点击资源后打开抽屉，关闭抽屉不会改变当前来源、筛选条件、列表滚动位置或选中资源。

## 交互与布局

- 使用 `ElDrawer`，方向为右侧，标题区域展示资源名称和版本。
- 桌面窗口默认宽度使用 `min(760px, 64vw)`；窗口较小时宽度接近全屏，但保留可见的关闭入口。
- 抽屉正文继续复用现有 `AssetDetail`，保留“预览、源码、文件、演进历史”和安装状态操作。
- 点击资源打开抽屉；点击遮罩、关闭按钮或按 Escape 关闭。
- 切换到另一个资源时复用同一抽屉并刷新内容，不先关闭再打开。
- 切换来源时沿用现有逻辑清空旧选中项，并关闭详情抽屉，避免旧资源与新来源混用。

## 组件边界与状态

- `App.vue` 负责抽屉开关状态，并根据 `explorer.selectedAsset` 驱动打开与关闭。
- `AssetDetail.vue` 继续只负责详情加载、标签内容和安装状态，不承担抽屉生命周期。
- `ResourceExplorer` 和 `AssetList` 不新增抽屉依赖，仅维持资源选择事件。
- 主网格 CSS 删除固定详情列；抽屉样式通过独立类覆盖 Element Plus 默认尺寸与滚动容器。

## 错误与加载行为

- 详情加载失败仍在抽屉内部显示现有错误信息。
- 加载新资源时清空上一资源内容，防止短暂展示旧详情。
- 关闭抽屉不取消已完成的列表扫描，也不重置筛选状态。

## 测试与验收

- 组件测试：选择资源后抽屉可见，关闭后隐藏，列表与筛选状态保留。
- 组件测试：切换来源时抽屉关闭，不发出旧资源与新来源组合的详情请求。
- E2E：选择中央资源打开详情抽屉，确认标签可见并可关闭。
- 实机视觉验收：在当前 Electron 窗口确认正文宽度、标签间距、滚动和小窗口尺寸。

## 范围外

- 不增加独立路由或新窗口。
- 不修改详情数据结构、Markdown 渲染和资源操作协议。
- 不引入可拖拽宽度或持久化抽屉尺寸。
